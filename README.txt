V6 — APPLICATION TABLETTE
La V6 est une Progressive Web App installable sur Android.
Pour l'installation complète, héberger le dossier sur HTTPS, ouvrir l'adresse dans Chrome, puis menu ⋮ > Installer l'application (ou Ajouter à l'écran d'accueil).
Le connecteur récupère articles et pages Blogger, avec contenu HTML, labels, dates, URL, images et localisation lorsqu'elle existe.
Commande : python connecteur_blogger_v6.py --api-key "VOTRE_CLE_API"
Puis importer blogger-export-v6.json dans la rubrique Mise à jour.
