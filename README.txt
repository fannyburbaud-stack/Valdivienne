VALDIVIENNE V1.1
Application PWA simple, adaptée à GitHub Pages.
Fichiers à placer à la racine du dépôt.
Pour utiliser la carte : exporter Google My Maps en KML puis utiliser « Importer KML ».
La géolocalisation nécessite l'autorisation du navigateur.
La V1.1 stocke les données localement pour la consultation hors connexion.
